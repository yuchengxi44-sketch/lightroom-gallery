# 光影集 · 摄影画廊（EXIF 版）

一个本地运行的摄影作品分享平台，支持上传、审核、浏览、EXIF 参数展示。

## 运行方法

需要先装 [Node.js](https://nodejs.org/)（LTS 版本，自带 npm）。

```bash
cd lightroom-gallery
npm install        # 安装依赖（只需一次）
npm start          # 启动
```

然后浏览器打开：**http://localhost:3000**

- 前台画廊：http://localhost:3000
- 管理后台：http://localhost:3000/admin （默认密码 `admin123`，可用环境变量 `ADMIN_TOKEN` 覆盖）

## 功能

- 上传照片（支持多图）/ 视频，需注册登录
- 提交后需管理员在后台审核通过才展示
- 灯箱大图自动显示 **EXIF 相机参数条**（相机/镜头/光圈/快门/ISO/焦距/拍摄时间）
- 灯箱 **下载原图** 按钮（原图直出，不压缩画质；多图可逐张下载）
- 后台管理员可 **删除作品**（作品记录 + 原图 + 浏览历史一并删除）
- 分类筛选、多关键词搜索、点赞、收藏、浏览历史、通知、热门话题
- 作者主页、敏感词拦截（词库在 `sensitive_words.json`，空数组，可自行添加）
- 被拒作品可在「我的投稿」重新提交
- 数据存本地文件：`data.json` / `users.json` 等

## 手机同 WiFi 访问

在同一局域网下，用手机访问电脑 IP + 端口 3000：
```
http://你的电脑IP:3000
```
（需确保防火墙/安全组放行 3000 端口）

## 存储与容量限制

- 图片存于项目目录下的 `uploads/` 文件夹
- 数据库（作品/用户/历史等）存同目录的 `data.json` 等文件
- 上传限制：
  - 单文件最大 **300MB**
  - 单次上传总量最大 **500MB**
  - 全站上传总容量上限 **30GB**（`server.js` 里 `MAX_STORAGE_SIZE`，可改）

## 技术说明

- 后端：Node.js + Express + Multer
- EXIF 提取：`exifr`（纯 JS，无原生编译）
- 数据：JSON 文件存储，无数据库
